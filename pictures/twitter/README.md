# FLAWEN / X profile

- `flawen-x-banner.png`: 1500 × 500 header.
- `flawen-x-avatar.png`: 400 × 400 avatar, designed for a circular crop.
- `profile-preview.png`: illustrative composition preview, not a screenshot of a published X profile.
- `projects/`: editable Studio JSON sources.

Created from the existing FLAWEN vector logo and typography, imported and exported through FLAWEN STUDIO. No AI image generation. Exports were visually inspected and their dimensions verified; browser errors are recorded in `manifest.json`.

To recreate: run Studio on port 5180, then `node scripts/export-twitter.mjs`. Override the local URL with `STUDIO_URL` if needed.
